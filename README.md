# THE US FILES | For Saumya, from Iftekhar ♡

This is the personalised edition of the 10-chapter interactive love-letter website. It includes the nickname Saumya, Iftekhar's signature, the shared “tato pani khau hai” warm-water texts, the playful chilled-vs-dramatic dynamic and the good-natured astronomy debate.

## Preview before sharing

Open `index.html` on your computer with Chrome or Edge. No installation required. The interactive experience works as a self-contained HTML file. Internet is only used to load optional Google Fonts; the site also works with fallback fonts.

## Put it online for free (GitHub Pages)

1. Download and unzip the website package.
2. Open https://github.com/new and create a **Public** repository, for example `for-saumya`.
3. On your empty repository, click **uploading an existing file**, and upload `index.html` from the extracted folder. Do not upload the ZIP.
4. Click **Commit changes**.
5. Go to **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
6. Wait a few minutes and refresh Settings → Pages. Select **Visit site** when GitHub says the site is live.

The URL should look like `https://YOUR-USERNAME.github.io/for-saumya/`. She can use the site directly from that link on her phone. No account required.

## Already have a repository?

If you previously uploaded an older version of this site, replace the repository's existing `index.html` with the new one. For small HTML files, you can open the existing file in GitHub and use the edit pencil, but uploading via the GitHub web uploader is easier when starting a new repository. Commit the changes, then wait for Pages to publish the updated version.
